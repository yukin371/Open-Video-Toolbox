# Desktop 工作台需求说明

## 1. 背景

旧的小丸工具箱曾经把本地视频转码、预设、批量队列、字幕和日志组织成一个低门槛工作台。Open Video Toolbox 已经具备相应的 Core/CLI 能力，但缺少面向非命令行用户的交互入口。

本需求参考其工作流价值，不复刻旧软件的实现、界面或全部预设。

## 2. 目标

让用户能够在一个本地 Desktop 工作台中完成：

1. 导入一个或多个视频文件。
2. 查看媒体信息和依赖状态。
3. 选择转码/剪辑预设和输出规则。
4. 可选接入本地转写、字幕、BGM、配音或其他 supporting signal。
5. 预览计划并加入队列。
6. 执行、取消、重试任务，并查看完整日志和输出产物。

## 3. 首版功能需求

### Must

- 文件与目录导入，支持多选。
- 媒体探测和依赖检查。
- 内置预设浏览、选择和少量参数编辑。
- 输出目录、文件名规则和覆盖策略。
- 单任务与批量任务队列。
- 任务状态：等待、运行、成功、失败、取消。
- 进度、耗时、当前步骤、错误摘要和原始日志。
- `edit.json` / preview 的查看与导出。
- 字幕导入、截取、双语文件接入和 sidecar/burn-in 选择。
- 本地 `whisper.cpp` 转写任务入口，翻译保留外部文件接口。

### Should

- 失败任务重试。
- 任务复制为新变体。
- 输出文件夹快速打开。
- 最近任务列表和工作目录恢复。
- 预设导入/导出。

### Won't in D1

- 完整多轨时间线编辑器。
- 专业调色、关键帧和复杂特效工作台。
- 内置 AI provider、在线翻译或模型下载中心。
- 账号、云端队列和远程执行。
- 复刻旧小丸工具箱的全部私有预设。

## 4. 用户验收

给定一批本地视频，用户可以在 Desktop 中选择预设并生成队列；队列执行后，每个任务都能看到成功/失败状态、原始外部工具日志、输出路径和可复查的结构化结果。发生失败时，用户能定位到具体输入、命令计划或外部工具错误，而不是只看到“执行失败”。

## 5. 约束

- Desktop 是交互壳，不是业务 owner。
- `edit.json`、`CommandPlan`、`ExecutionResult` 和 Core 字幕/转写模型是共享边界。
- 所有外部工具调用保留完整日志与错误输出。
- 文档中的“自动翻译”只表示接入外部翻译结果，不表示仓库内置翻译服务。
