# Core.Presets

> 最后更新：2026-10-13

## 职责

维护转码预设模型、内置压缩预设以及显式 JSON 预设目录的加载与校验。
压缩预设描述单素材编码参数；编辑计划模板由 `Core.Editing` 承接。

## 数据流

内置预设 + CLI 显式传入的预设文件/目录 -> 合并并校验 -> 任务模型 -> `Core.Execution` 构建命令。
CLI 只负责传入路径、选择 id 和呈现加载错误，不复制 JSON 加载逻辑。

## 约定 & 陷阱

- 不隐式扫描用户配置目录，不引入持久化预设服务。
- JSON 文件可以是一个预设对象或一个预设数组；目录只读取顶层 `*.json`，按路径排序。
- id 大小写不敏感，自定义预设不能覆盖内置 id，也不能互相重复。
- `schemaVersion` 使用现有 v1 预设模型；加载失败要保留文件路径和错误原因。
- 扩展名只接受可选前导点和字母数字，避免把路径当作容器扩展名；已声明的编码器名称不能为空。
- `outputNameSuffix` 为文件名后缀，不能是路径；省略时 CLI 使用 `_<presetId>`。
- 默认同目录输出和显式目录/名称覆盖由 CLI 组装为 `JobOutput`；最终路径由 `Core.Execution` 构建。
- 编码器是否在本机可用由外部工具执行确认，catalog 不启动外部进程。
- CRF 预设不保证文件一定缩小；`copy-aac-mkv` 复制视频，仅转换音频与容器。
- 参数、命名约定或加载语义变化时，同步命令说明、使用指南及相关测试。
